This lab demonstrates host‑based firewall control using UFW on Ubuntu. ICMP echo requests (pings) are commonly used for reconnaissance and can be abused in denial‑of‑service (DoS) attacks. By modifying UFW’s configuration, I blocked inbound ICMP echo requests to harden the host against these risks. 
This lab has a succesful ping attempt from the attacker vm with Parrot Security OS to the Host Ubuntu VM. Then I adjusted the before.rules nano file for UFW on the ubuntu vm than prevented any ICMP echo requests to connect to the Host Ubuntu VM. Then I have attached a screenshot of the attacker vm pinging the host vm with an unsuccessful ping attempt.
